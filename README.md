# ⚔️ The Order of Znak Multiverse

> The digital garden and collaborative campaign chronicle for **The Order of Znak** and **The Acolytes of Znak**, collaborating across tabletop campaigns run by Peter and Gary.

🌐 **Live Website:** [https://orderofznak.github.io](https://orderofznak.github.io)

---

## 🗺️ About This Repository
This repository contains the static site generator ([Quartz v4](https://quartz.jzhao.xyz)) and public campaign notes for the Znak multiverse:
- **`content/order_of_znak/`**: Complete campaign chronicle, character sheets, and lore from the original D&D 5e dual-character saga.
- **`content/acolytes_of_znak/`**: Campaign plan and character sheets for the upcoming Barovia (*Curse of Strahd*) campaign.
- **`content/index.md`**: The central portal and campaign matrix.
